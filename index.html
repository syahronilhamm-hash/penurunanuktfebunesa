Pengaturan Integrasi Otomatis Google Sheets

Masukkan URL Google Apps Script Web App agar data yang diisi mahasiswa di web ini langsung terkirim secara real-time ke Google Sheets privat milik Admin tanpa perlu mendownload file CSV.

Langkah Praktis Menghubungkan:

  1. Buka Google Sheets privat Admin → Klik menu Ekstensi > Apps Script.
  2. Paste skrip penerima data → Klik Deploy > New Deployment.
  3. Pilih type Web App, akses: Anyone (Siapa Saja).
  4. Salin Web App URL dan tempelkan di kolom atas.
